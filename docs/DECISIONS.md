## 已发生的核查记录

- 目录检查：`D:\project\PawMeet` 为空，`git status` / `git rev-parse` 返回不是仓库。这是初始状态，不是应用故障；按用户要求在 Phase 0 初始化。
- 工具核查：Node 24.15.0、npm 11.12.1、pnpm 11.19.0、Git 2.54.0 可执行；Git 已有用户身份。npm 官方 registry 元数据查询成功，未安装依赖。
- 官方资料核查：GLM 当前对话文档与结构化输出指南给出 JSON 模式，因此未将 `json_schema` 严格输出作为既定能力；高德资料支持 serviceHost 代理。来源集中见 [ARCHITECTURE](ARCHITECTURE.md#9-外部依据与待验证项)。这是文档核查，非 API 实测。
- 高德固定 `/_AMapService` URL 与 Next 私有目录前缀存在冲突，物理目录使用 `app/%5FAMapService`，已由生产构建和真实 SDK 请求确认路由可达。
- 地图固定上游使用 Node HTTPS 适配器：本机原生 fetch 连接高德存在超时，HTTPS 请求可成功；保留总超时、响应上限、无重定向、脱敏错误。网络仍可能超时，不静默重试或伪造 POI。实现、mock 与真实联调证据统一见 [PROGRESS](PROGRESS.md)，没有线上部署；真实模型结果独立记录于AI_EVAL。
