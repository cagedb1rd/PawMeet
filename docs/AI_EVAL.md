## 2. 评测固定条件与判定

- 未来 runner 路径 `evals/runner/`，用例 `evals/cases/core.v1.json`，报告 `evals/reports/<runId>.json` + 可读摘要。当前只定义文档用例，不创建业务代码或运行器。
- 固定评测时刻 `2026-10-17T02:00:00Z`（中国当天 10:00），时区 Asia/Shanghai；线上服务使用自身当前时间，只有本地评测入口可注入 clock，不允许生产客户端任意覆写 now。
- 测试上下文是独立虚构 fixture：当前用户 ua，拥有 pa（豆包，24 月史宾格，中型、温和、爱散步）和 pb（团子，小型）；其余候选由规则测试 fixture 提供，不依赖未来真实种子 ID。需要主人习惯的用例单独给明，未给的信息不得当作已知。
- 所有任务须符合 ARCHITECTURE 的统一响应与各任务 draft Schema。用例中的 null 表示不确定；clarifications 指向相关字段；文字允许等义表达，字段值 / 引用 / 日期用确定断言。
- 自动判定包括：原始 JSON 是否可解析；输出 Zod 是否通过；期望字段；禁止新增实体 / 错误单位 / 时间；草稿是否错误绕过澄清。建议文字另按人工 rubric 判定，不使用另一个 LLM 当唯一裁判。
- 每例状态 `not_run/pass/fail/error/skipped`。交通 / 网络 / 额度失败记 error，不能从分母悄悄删除；skipped 要说明原因，核心套件有 skipped 就不能宣称完整通过。
- 分别计算原始模型首轮 Schema 成功率、语义正确数 / 全部 live 用例数、澄清召回率（需要澄清子集）、实体忠实违规数、危险建议数、p50/p95 耗时与 usage。校验器成功拦截错误不等于模型首轮正确。
- 交付目标：35 条至少各执行 1 次；语义通过率 ≥95%（至少 34/35）、原始 Schema 成功率 ≥95%；进入 UI 的成功结果必须 100% 通过输出及语义防线；不存在实体 / 编造距离 / 未确认写入 / 危险照看建议为 0。任一关键风险失败必须修复或明确禁用对应能力，不能被总体分数抵消。
- 首轮后对 C03、C05、M03、M05、M07、H03、H04、H06、L03、L06 额外各跑 2 次（最少 55 次核心 live 调用），单列重复稳定性；预算允许再跑全套 3 次。不要把一次成功当作稳定保证。
- 先取得密钥与明确预算，预估最坏 token / 次数；runner 支持 `--dry-run` 只列用例与预算、`--case`、`--max-calls`、中断续跑，不自动重试无限调用。真实评测运行在获准本地 / 专用环境，也受预算保护，不能开放公网“评测绕过限流”接口。

## 4. 确定性 / mock 故障套件（另计，不计入 35 条模型效果）

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| T01 | 空输入、1501 字、超 24KiB 请求、未知 task / 多余字段 | 上游调用 0 次，400 / 413，字段错误可读 |
| T02 | GLM 401 / 403 / 429 / 5xx、断网 / 超时 | 显示真实失败类别 / requestId，密钥脱敏，不显示成功卡片 |
| T03 | content 非 JSON、缺字段、错误 enum、超数组长度、截断 finish_reason | 502；输出不能进入确认保存流程 |
| T04 | 返回不存在 petId、非法日期、客户端试传 model / URL / Prompt | 白名单 / 语义校验拒绝，客户端参数不改变上游目标 |
| T05 | 连点生成 / 反复换身份 / 新建匿名 cookie / 伪造来源 IP | 并发、会话、IP、全局限制分别生效；身份切换不刷新额度 |
| T06 | 重启进程、账本损坏 / 不可写、上游响应缺 usage | 日额度持久化；不可恢复 503 关闭调用；未知消费按最坏预留 |
| T07 | 生成后切身份 / 编辑源宠物 / 取消草稿 / 确认前刷新 | 不写错主人或旧 revision；取消后持久化无业务变化 |
| T08 | 同一个 5km 条件下列表 / 地图、0 结果、同分稳定排序 | 使用程序结果且两视图 ID 一致；不自动造宠友或扩大半径 |
| T09 | 注入 script / HTML / 任意链接到输出字符串 | 按纯文本渲染，不用 dangerouslySetInnerHTML；不自动访问链接 |
| T10 | 超日额度与全局并发、请求取消但已抵达上游 | 拒绝在调用前发生；已预留消费不能因为浏览器取消而错误退还 |
